# H3 사전등록 — 장치의 섹터 금리 민감도는 단순 대안보다 나은 리스크 측정 도구인가

- 등록일: 2026-10-22 (이 파일과 `h3_risk_test.py` 를 담은 커밋이 사전등록 시점)
- 오너 승인: 2026-10-22 ("리스크 관리 용도 + 레짐 판단" 질문 → H3 하나로 묶어 진행 승인)
- 상태: **등록 — 판정 데이터 미확인** (H3 지표는 어떤 구간에서도 계산한 적 없음)

## 질문

H1 은 장치가 *방향이 맞는 섹터를 고른다*는 것을 보였다(등급 C PASS). 리스크 도구에 필요한 건 그 이상이다:
**금리 충격일에 섹터별 손익을 단순한 대안보다 더 정확하게 예측하는가.** 장치가 고정 교과서 목록이나
단순 기울기보다 낫지 않다면, 리스크 관리에 이 회귀·FDR 기계를 쓸 이유가 없다. (알파 질문 아님.)

## 모델 — 크기는 공통, 다른 것은 '어느 섹터를 어느 방향으로 보느냐'

거래일 d 마다 **d−1 까지의 데이터만** 사용. 섹터 s 에 대해:

- 헤지: β_s = 직전 126 관측 OLS(섹터 ~ SPY) (H1·운영과 동일). 실현값 y_s,d = R_s,d − β_s·R_SPY,d.
- 공통 크기: slope_s = 직전 370 관측에서 (R_s − β_s·R_SPY) 를 ΔUS10Y 에 단순 회귀한 기울기
  (같은 β_s 를 창 전체에 적용).
- 예측 ŷ_s,d = b_s · ΔUS10Y_d. 모델별 b_s:

| 모델 | b_s | 의미 |
|---|---|---|
| zero (보고용) | 0 | 금리 정보 없음 |
| **textbook** | w_txt·\|slope\|, w_txt: XLU −1, XLRE −1, XLF +1, 나머지 0 | 교과서 목록 (유틸·리츠 = 채권 대용, 은행 = 금리 수혜) |
| **naive** | slope (부호 그대로, 전 섹터) | 단순 기울기, 선정 없음 |
| **apparatus** | w_app·\|slope\|, w_app = H1 `select()` (롤링 370, 운영 규칙) | 장치: 다변량 partial + BH FDR + δ 임계로 선정·방향 |

운영은 라벨만 쓰고(동일 가중) 크기를 쓰지 않으므로, 크기는 세 모델 공통의 단순 기울기로 준다.
따라서 이 검정이 재는 것은 **장치의 선정·방향 판단이 교과서 목록과 단순 기울기보다 나은가**이다.

- 유효 섹터: β 는 직전 126 중 유효 ≥100, slope 는 직전 370 중 유효 쌍 ≥250, y_s,d 유한. 같은 날 모든 모델이
  같은 섹터 집합으로 평가된다.

## 판정 대상 = 금리 충격일

충격일: |ΔUS10Y_d| ≥ 직전 370 관측 |ΔUS10Y| 의 90% 분위 (d−1 까지로 계산, 약 10% 의 날).
리스크 관리가 실제로 묻는 "금리가 크게 움직인 날 무엇이 얼마나 다치나"에 해당.

## 손실과 검정

- 충격일 d 의 모델 손실 L_m,d = 유효 섹터 평균 (y_s,d − ŷ_m,s,d)².
- 비교 2개: D_txt,d = L_textbook,d − L_apparatus,d, D_naive,d = L_naive,d − L_apparatus,d (양수 = 장치가 나음).
- 통계량: D 평균의 Diebold-Mariano t, Newey-West(lag 5) 표준오차 (충격일을 날짜순 시계열로).
  단순 t 는 보고만 (H1 에서 단순 t 가 NW 의 약 2배였던 것을 반영해 이번엔 NW 로 판정).
- 구간: **2003-01-01 ~ 2024-12-31** (H1 등급 C 와 같은 원자료 `output/h1_levels_hist.csv`), 전반 ~2013 / 후반 2014~.

## 판정 기준

**통과 = 두 비교 모두 (평균 D > 0, NW t ≥ 2.0, 전반·후반 평균 D > 0).** 그 외 = 기각.
둘 다 이겨야 통과(교집합 검정)이므로 다중검정 보정 없음. H3 의 유일한 판정 규칙. 기각 시 충격 분위·창·
손실함수·교과서 목록을 바꾼 재시도 없음.

## 보고 (판정 아님)

- 모델별 설명 비율 ES_m = 1 − ΣL_m / ΣL_zero (충격일, 전체일), 절대오차 버전 DM, 섹터별 ES.
- **레짐(탐색)**: G_d = 장치 선정 섹터 수 / 유효 섹터 수 (d−1 정보, '금리가 섹터를 얼마나 끄는가' 계기판).
  - 연도별: 평균 G, 충격일 수, 모델별 ES.
  - 비중첩 63일 블록: RI_b = 블록 안 섹터별 (y_s 를 ΔUS10Y 에 회귀한 R²) 평균 = 그 분기에 금리가 섹터를 실제로
    얼마나 끌었나. OLS RI_b ~ G_b(블록 첫날) 와 RI_b ~ G_b + RI_{b−1} (직전 분기 실현값 대비 증분), NW(lag 2).
  - 사전 해석: G 의 계수가 양수이고 RI_{b−1} 을 넣어도 남으면 "레짐 계기판으로 단순 지표 이상의 정보",
    양수지만 증분이 없으면 "레짐을 읽긴 하지만 직전 분기 실현값으로 대체 가능", 아니면 "레짐 판단 근거 없음".
    탐색 결과이므로 유망해도 별도 사전등록·전향 검증 전에는 주장하지 않는다.

## 오염 고지

- H1 등급 C 결과(같은 데이터·같은 선정 규칙)의 집계를 봤다: 섹터별 지속성 XLRE·XLF·XLU·XLE·XLK 강함,
  전반 약함. 교과서 목록(XLU·XLRE·XLF)은 일반 지식으로 정했지만 H1 의 강한 섹터와 겹친다 → **교과서
  기준선에 유리, 장치에 불리**한 방향의 오염 (보수적).
- H1 에서 연도·분기별 선정 수 시계열은 보지 않았다(집계만 출력). H3 의 충격일 손실·RI 는 어떤 구간에서도
  계산한 적 없다.

## 사전 해석

- PASS: 장치의 선정·방향이 교과서와 단순 기울기 모두보다 금리 충격 손익을 잘 맞춘다 → 노출 보고·스트레스
  테스트에 장치 라벨을 쓸 근거. 여전히 알파 아님.
- REJECT 이고 naive 가 앞섬: 선정(0 으로 깎기)이 정보를 버린다 → 리스크 측정엔 단순 기울기.
- REJECT 이고 textbook 이 앞섬: 교과서 목록으로 충분.
- 기각 시 어떤 모델을 쓸지는 자동 결정 아님 — 결과 보고 후 오너 결정.
